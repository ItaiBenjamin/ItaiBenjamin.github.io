Programmed an STM32 microcontroller in C to autonomously follow a line and navigate a maze using four QTR-1RC reflectance sensors and an HC-SR04 ultrasonic sensor.

Configured TIM3 PWM across four channels to drive an SN754410 H-bridge for bidirectional DC motor control, and wrote a real-time sensor feedback algorithm for line following and sequential obstacle detection for maze navigation.

**Skills:** C, STM32, PWM motor control, sensor fusion
